# Phase 5 – how to add tests to your repo

1. Copy the tests/ folder into your CS4433-LMS project root.
2. Append the contents of CMakeLists_tests_snippet.txt to your CMakeLists.txt
3. Build and run:
   cmake -S . -B build && cmake --build build
   ./build/lms_tests
4. Fill in Section 5 (results) and Section 6 (defect log) in the Word document after you run the tests.
