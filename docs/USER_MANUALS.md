# User manuals – Moderated LMS v1.0

Start the program (`lms` or `lms.exe`). At the prompt enter username and password. Type `quit` to exit.

---

## A. Administrator

**Demo account:** `admin` / `admin123` (change after install)

| Menu option | What it does |
|-------------|--------------|
| Create department | Add a department (e.g. Mathematics) |
| Create user | Add Student, Lecturer, HoD or Administrator |
| Create course | Link a course to a department and optional lecturer |
| Enrol student | Place a student on a course |
| Logout | Return to login |

**Tips:** Create the department first, then users, then courses, then enrolments.

---

## B. Lecturer

**Demo account:** `lec1` / `lec123`

| Menu option | What it does |
|-------------|--------------|
| Create assignment | Set title, description, deadline, maximum mark |
| List submissions | See work for an assignment |
| Mark submission | Enter numeric mark and **written feedback** (required) |
| Grant extension | New deadline for one student with a reason |
| Logout | Return to login |

**Rules:** Marks are not visible to students until the HoD releases them. Late work is penalised automatically when marked.

---

## C. Head of Department (HoD)

**Demo account:** `hod1` / `hod123`

| Menu option | What it does |
|-------------|--------------|
| View marked submissions | List marked work in your department |
| Moderate mark | Accept the mark, or change it **with a reason** (logged) |
| Release mark | Make mark and feedback visible to the student |
| Logout | Return to login |

**Rules:** A reason is required when changing a mark. Only release when moderation is complete.

---

## D. Student

**Demo account:** `stu1` / `stu123`

| Menu option | What it does |
|-------------|--------------|
| List my assignments | See assignments for enrolled courses |
| Submit work | Enter text for an assignment (resubmit allowed before deadline) |
| Logout | Return to login |

**Rules:** After the deadline, submissions are marked Late and a penalty may apply. You only see marks after the HoD releases them.

---

## Security note for all users

- Do not share passwords.
- Log out when finished on a shared computer.
- Report login problems to the administrator.
