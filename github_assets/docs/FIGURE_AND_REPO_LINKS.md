## GitHub links

For a direct GitHub link to an asset, use this repository path pattern:

```text
https://github.com/katlehochristophersenqhe-maker/CS4433-LMS/blob/main/github_assets/docs/diagrams/01_architecture.png
```

Replace the final filename with the asset you want to reference. The media
filenames include spaces; GitHub links should encode those spaces as `%20`.
